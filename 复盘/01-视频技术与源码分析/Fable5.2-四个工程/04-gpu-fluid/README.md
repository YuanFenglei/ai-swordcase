# GPU 流体（Godot 4.7.2，RenderingDevice 计算着色器）

粒子全程在显存里：模拟在主渲染设备上跑 MLS-MPM，渲染用 CompositorEffect 做屏幕空间流体，粒子位置不回读 CPU。

## 运行

```
godot --path .                      # 游戏
godot --path . -- --demo            # 自动演示，循环播放（录屏用）
godot --path . -- --shots           # 截图到 _shots/，打印 20万/50万/100万 的帧率后退出
godot --path . -- --shots --bench=300000,750000   # 只跑指定粒子数的基准
godot --path . -- --demo --autoshots                # 演示跑一轮，每 3 秒存一张图后退出
godot --path . -- --selftest                        # 自动把沙盒开关和游戏流程过一遍后退出
godot --path . -- --particles=500000              # 游戏/沙盒的粒子规模
```

## 游戏

75 秒内开船捡完 8 个浮标。12 秒后闸门自动打开放水。船翻过去超过 2.5 秒算输。

## 模拟

每个子步 3 个计算着色器（`shaders/`）：

1. `p2g1` 粒子 → 网格：质量、动量、染料，用定点整数 `atomicAdd` 散射。压力（Tait 状态方程）和粘性应力并进仿射项里一起散射，密度用上一步 `g2p` 采到的值按速度散度外推一步
2. `grid` 网格更新：重力、鼠标力、碰撞体（盒 / 球的解析 SDF，带线速度和角速度）、边界；顺带把密度和染料写进 3D 纹理
3. `g2p` 网格 → 粒子：速度、APIC 仿射矩阵、密度、平流、碰撞体挤出、泡沫

另外每帧一次：`probes`（在刚体的探针点附近统计水的占比和流速，异步回读几百个 float，用来算浮力和阻力）、`column`（每列水深写进 2D 纹理，池底着色器用它画焦散）、`spawn`（在 GPU 上生成粒子，用于初始填充和喷口）。

60 帧时每帧 2 个子步。

## 渲染

`fluid_fx.gd` 是一个 CompositorEffect，挂在不透明物体之后、透明物体之前：

1. 实例化四边形画球形 impostor，输出线性深度和球面法线 / 速度 / 泡沫
2. 窄域滤波（narrow-range filter）分离式平滑深度，两轮
3. 合成：由深度重建法线，折射采样场景颜色，沿折射方向在密度 3D 纹理里步进求厚度和染料比例，Beer-Lambert 吸收，菲涅尔反射程序化天空，太阳高光，泡沫

`wipe` 参数控制「粒子视图 / 液体视图」的分界线。

## 文件

- `main.gd` 场景、关卡、游戏、沙盒、演示、截图和基准
- `fluid_sim.gd` 模拟（缓冲区、uniform set、调度）
- `fluid_fx.gd` 屏幕空间流体
- `shaders/*.glsl` 计算 / 光栅着色器，运行时用 RDShaderSource 编译
- `floor.gdshader` `props.gdshader` `sky.gdshader` 场景材质

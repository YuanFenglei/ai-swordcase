# 主游戏代码架构

正式版是独立 Godot 工程。项目默认加载 `full_game/main.tscn`。场景脚本继承工程内的球面基类，创建 `GameWorld`、世界视图与 HUD，绑定输入、相机可见性、角色贴纸命中查询和 UI 请求。默认启动进入主菜单，开始游戏后创建新局。[工程配置](../../src/game/project.godot) · [主场景](../../src/game/full_game/main.tscn) · [场景脚本](../../src/game/full_game/main.gd)

## 一次物理步

1. 默认物理频率为 60 Hz。主场景将摇杆或键盘输入交给 `GameWorld.advance(delta, suspended, motion)`。每个可模拟的物理帧先移动，再用同一个步长推进探索与战斗，步长上限为 0.1 秒。[主循环](../../src/game/full_game/game_world.gd)
2. 每步推进角色、攻击和地格计时，更新节点焦点、刷怪与敌方行为。接着推进染色、彩碑启动和笔触，处理星灵移动与攻击、地伤及节点完成。只有仍允许探索或战斗时才继续处理拾取、伙伴与待选强化。
3. 暂停或打开决策面板时冻结模拟。复色期间单独推进演出钟，1.5 秒入账碎片，1.8 秒结束演出。普通碑在领取或跳过伙伴后结算升阶。最终碑发出完成信号，世界协调升阶和经验强化，HUD 同时保留离场与升阶消息。[关卡](../../src/game/full_game/level_system.gd) · [成长](../../src/game/full_game/progression_system.gd)
4. 物理帧同步角色并采集移动样本，绘制帧据此插值主角、镜头和移动节点。常规世界特效与 HUD 每累计 0.08 秒刷新一次，动作命令也可主动刷新。[场景回调](../../src/game/full_game/main.gd) · [移动插值](../../src/game/full_game/movement_interpolation.gd)

## 规则与显示的连接

| 入口 | 读取或提交的数据 |
| --- | --- |
| 玩家操作 | HUD 发出 `action_requested`，场景通过 `ui_action` 将操作转给世界门面。奖励选择携带决策 ID，追踪命令只改变导航。换星由关卡在传送门计时完成后核对星球号并推进。 |
| 世界显示 | 场景以 `DisplaySnapshotCache.capture(run)` 供应角色、笔触和地表快照。`world.gd` 按快照更新模型、材质和动画。 |
| 碰撞查询 | 空间适配器使用表面几何与贴纸命中回调，主场景提供相机及可玩区域可见性。一次模拟步内镜头不动，`view_step()` 按坐标复用可见性与屏内判断，步外查询照常直接调用。模拟决定命中是否写色、扣血或触发死亡。 |
| 生命周期 | 新局、换星球、加载和结束通过世界信号通知场景。空间代次和地格修订号驱动缓存重建。 |

建筑和静态场景表面颜色保留至恢复或换星球；地色不再按时间消退，8秒仅控制地伤。敌人及尸体的身体色随对象保留，友方身体不可染。离开节点不会重置覆盖率。旧清地入口继续处理未恢复地面的战斗色，不清建筑或永久恢复状态。

## 职责与接口

[node_activation.gd](../../../src/game/full_game/node_activation.gd)唯一管理节点倒计时，进度归Run的节点字段`activation_elapsed`；[专项](../../../src/game/full_game/node_auto_activation_test.gd)覆盖自动流程，UI与建筑材质只读显示。存档允许旧档缺此字段，存在时必须是0到2的有限数；主档和checkpoint均校验。

| 模块 | 职责 |

| [paint_state.gd](../../../src/game/full_game/paint_state.gd) | 地面写色、局部表面/身体颜色、覆盖面积、恢复清理；状态唯一归属Run |

发射数据含id、source、color、pos、velocity、target、life、round；命中含surface、actor、position、normal，身体命中另带uv和height。世界坐标以球心为原点，米制。表面记录按稳定ID保存采样颜色及revision。`data.ground`继续是地面唯一颜色数据与旧系统查询视图，不另复制一份地面状态；其写入集中到PaintState。UI快照排除大体积paint数据。

二维对象碰撞使用当前贴纸平面和源图Alpha，透明像素不挡弹；局部颜色保存在32×32身体遮罩上。该方案是二维角色表面的近似，非拥有厚度、前后皮肤的三维角色网格。无窗口纯Run测试没有渲染场景对象代理，实际身体/遮挡链路另由场景测试验证。

## 三维爆裂表现

按追加要求委派子Agent制作[闭合三维资产](../../art/颜料表现/三维颜料爆裂资产.md)，正式场景弹体、液滴及[爆裂组件](../../../src/game/full_game/paint_burst_visual.gd)均已接入。碰撞后核心膨胀，厚实喷溅瓣向三维方向展开并分离成滴，0.55秒内收尾；湿颜料专用材质按真实网格法线产生侧缘暗部和高光。第一次平色版本体积感不足，已改为连续明暗并复查GPU。装饰瓣读取物理液滴初始方向，但不承担碰撞或新增染色；真正染色仍来自有限液滴首次接触。

Godot支持[射线和形状扫掠](https://docs.godotengine.org/en/stable/classes/class_physicsdirectspacestate3d.html)，可实现这种接触驱动的局部染色；本工程采用同一网格的TriangleMesh线段求交及球体解析碰撞，便于无窗口模拟。Compatibility不支持[内置Decal](https://docs.godotengine.org/en/stable/tutorials/3d/using_decals.html)，因此局部色斑用独立颜色纹理实现。有限液滴接触近似不等于完整流体模拟。

## 参数与兼容

| 参数 | 当前值及边界 |
| --- | --- |
| 物理步长／弹速 | 1/60秒／14米每秒；点状弹心连续线段扫掠，不将显示球半径作为厚球碰撞 |
| 液滴 | 每爆96滴，最长0.8秒，最远2.5米，重力9.8米每二次方秒 |
| 色斑／采样 | 半径0.46米；静态网格最长边目标0.24米细分，面积按微三角计，背面与遮挡再次过滤 |
| 表现质量 | 低特效仅抽样显示液滴，全部96滴模拟及面积不变；完整流体、黏度、流淌和混色未实现 |
| 渲染 | Godot4.7.2 Compatibility，独立颜色纹理与卡通材质，无内置Decal依赖 |

仍使用原v3外壳文件，增加版本1的`paint`块（surfaces、bodies、projectiles、droplets、bursts、next_id、accumulator）。保存三维向量、颜料归属和在途状态，不保存Node、ImageTexture或TriangleMesh；JSON采用完整浮点精度，读回恢复整数ID/颜色。主档与checkpoint验证新字段，损坏主档按原路径尝试备份，并明确显示校验失败/备份恢复消息。备份恢复后再保存，将坏主档保留为`.rejected`序列，不覆盖有效备份。自动现场写盘节流至最多每0.5秒一次，显式保存仍立即执行。

旧档缺paint块时迁移为空表面：未激活节点旧充能清零，已进入守卫战/已完成状态保留。不会把50%旧计数伪造成半栋色斑。换星球清理在途状态与旧表面；新模型版本若改变采样编号，需要增加迁移，不能直接套用旧编号。

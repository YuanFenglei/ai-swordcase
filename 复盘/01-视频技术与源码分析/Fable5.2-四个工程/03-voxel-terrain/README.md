# 体素地形

Godot 4.7.2，纯 GDScript + 着色器。512×160×512 密度场（4194 万体素），10240 个 16³ 区块，Marching Cubes 网格，可实时挖、填、平滑、爆破、钻隧道。

## 运行

```
Godot_v4.7.2-stable_win64.exe --path <本目录>                 # 可玩模式
Godot_v4.7.2-stable_win64.exe --path <本目录> -- --demo       # 自动演示，约 100 秒，循环
Godot_v4.7.2-stable_win64_console.exe --path <本目录> -- --shots   # 截图 + 性能数字，自动退出
```

其他参数（跟在 `--` 后面）：

- `--demo --frames`：演示只跑一轮，每 3 秒存一张缩略图到 `_shots/demo_XX.png`，然后退出
- `--selftest`：可玩模式自检，依次用五种工具，再钻一条隧道走进去，存图后退出
- `--bench`：逐项开关渲染特性，打印每项的帧时间
- `--bench2`：逐项开关爆炸特效，各跑一轮爆炸压测并打印帧时间

## 结构

- `shaders/worldgen.glsl`：计算着色器，两遍。第一遍算 2D 高度图，第二遍算整块密度和材质体积，读回成两个字节数组。
- `scripts/mc_tables.gd`：启动时生成完整 256 种情况的 Marching Cubes 表。
- `scripts/voxel_world.gd`：数据、编辑、网格、碰撞。
  - 编辑在一个工作线程里按顺序执行，记录实际改动的包围盒，只标脏相交的区块。
  - 脏区块按到相机的距离排序，用 WorkerThreadPool 并行生成网格；线程里直接建好 ArrayMesh（含只有位置的合并顶点版本，给阴影和深度预通道用）。
  - 主线程每帧按时间预算换网格、更新 ConcavePolygonShape3D；新网格到位前旧网格一直显示。
  - 法线取密度梯度，区块边界两侧读的是同一份数据，所以没有接缝。
  - 每个顶点沿法线采样密度得到大尺度遮蔽，洞里的天光靠它压暗。
- `shaders/terrain.gdshader`：每个三角形带三个材质编号，按重心坐标混合；三平面投影的程序化细节、岩层色带、矿脉发光、雪线、弹坑余热。
- `scripts/fx.gd`：爆炸、碎石刚体、尘土、陨石，全部对象池。
- `scripts/director.gd`：演示和截图的镜头脚本。
- `scripts/player.gd`、`scripts/hud.gd`：角色控制器和界面。

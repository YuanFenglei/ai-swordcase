# Fable 5.2 · Godot 四个工程

Godot 4.7.2（Forward+）。四个文件夹各是一个独立工程，用 Godot 导入对应的 project.godot 即可运行。

| 文件夹 | 内容 |
|---|---|
| 01-zero-asset | 零素材 3D 游戏《蚀原》 |
| 02-rts-10k | 万人同屏 RTS |
| 03-voxel-terrain | 可破坏体素地形 |
| 04-gpu-fluid | GPU 流体 |

自动演示（视频里的画面）：

    godot --path 01-zero-asset -- --demo

按键和其他启动参数见各工程的 README.md。

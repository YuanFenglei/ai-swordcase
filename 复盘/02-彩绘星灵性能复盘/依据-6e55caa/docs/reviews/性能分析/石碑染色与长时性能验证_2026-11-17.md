# 石碑染色与长时性能验证

## 范围与现状

用户要求修改正式版节点楼房、让草原地物能被攻击染色，并排查玩久卡顿；后续明确暂不处理UI。本轮只改本地正式工程，不提交、推送、打包或发布，不读取或覆盖玩家真实存档。其他会话正在做的成长和UI改动保留，验证时另建只含本轮文件的隔离副本，不能把其结果算成本轮结果。

- 真实节点原来仍由[表面注册器](../../../src/game/full_game/paint_space.gd)生成房屋；单改草原装饰中的石碑不会替换真实节点。现由[石碑几何](../../../src/game/full_game/stele.gd)共同提供四部位的显示和碰撞，双阶底座、上下碑身及尖冠总高约6.365米，保留节点ID和3米内停留2秒自动开启规则。
- [地物染色显示](../../../src/game/full_game/decor_dye_view.gd)读取权威地格当前顶层颜色，使用96×96、每格0.5米的局部纹理供草原簇群材质采样；不新增一套染色存档，不改变灌木密度和原随机序列。恢复区不叠新染色。当前是地面颜色向地物的投影，不是每片叶子的独立弹道碰撞或微三角颜料存档。
- [旧表面迁移](../../../src/game/full_game/paint_geometry_migration.gd)先按旧几何严格验证，再在同节点部位或同装饰来源内按位置和法线重采样到新几何。保留局部染色比例的空间近似，不承诺每个旧微三角逐一保形；地色、随机流、节点进度、奖励和敌人等玩法字段不得随之改变。当前局与checkpoint均迁移，重复读档幂等。
- [喷溅显示](../../../src/game/full_game/splash_frame_fx.gd)将逐顶点的ImmediateMesh调用换成Packed数组一次提交的ArrayMesh，缓存球面细分位置与法线，缓存上限4096块；质量、半径、种子或星球变化时失效，清空地色时释放缓存。不减少原细分、层数或UV，不修改地色永久保留、每格最多两层、8秒地伤、友方免染及最多10具尸体规则。

## 诊断与修改前失败

任务固定基准为`35b465a48b1a285dd4467a1cc9eb913d83e9b8b1`。使用真实[main场景](../../../src/game/full_game/main.gd)，六只一阶伙伴、静止主角与移动高血量敌人，手动驱动3000步×0.1秒；每步都走物理与显示入口。它是300模拟秒的加速压力夹具，不是自然游玩五分钟、整球漫游或手机实测。

- 首次原版无窗口压力夹具当时记录13项通过，30秒段物理均值31.56→末段38.42毫秒、末段P95为77.14毫秒。收口发现同一路径的原始JSON已被后续120模拟秒插桩覆盖，因此这些数字仅保留为历史观察，不作为最终成对量化验收；当前可核对的无窗口原版资料是7项通过的插桩诊断。最终定量结论只使用下文完整保留的窗口GPU前后对照。
- 120秒分段插桩用于定位，不计入前后性能比较。末30秒喷溅构网约占brush显示耗时的69%；自动存档编码及写盘仍是另一处尖峰来源。本轮只改构网；编码替代方案收益小，保留原编码与原子写盘/备份/回滚路径，不牺牲存档可靠性。
- 石碑/地物新场景测试在原版真实main中154项、7项失败，定位到四部位仍为旧房、节点高度不符和地物没有接入染色材质；记录见[_local原版日志](../../../_local/formal-architecture/20261117T095347_760029Z/logs/stele_dye_scene_test.log)。
- 批量网格契约原版44项、16项失败，失败均为“必须一次Packed上传”的类型契约；原逐顶点几何oracle本来就通过。修复后独立oracle逐顶点比较位置、法线、颜色和直接计算的贴图UV，误差阈值0.0001，并检查权威数据只读及缓存上限。

## 验证进度

本轮专项已完成；包含其他会话改动的完整工作区共18组，17组通过，1组旧容量断言失败，不能称全套通过。分阶段结果、完整GPU分段数值、命令、日志哈希及源码哈希保存在[持久机器记录](石碑染色与长时性能验证_2026-11-17.json)。

- 仅替换喷溅网格的无窗口300模拟秒压力夹具13项通过，末段物理均值29.94毫秒、P95为62.46毫秒，原始数据仍在。历史约22%/19%的改善估算因原版原始数据被后续插桩覆盖而不作正式成对验收；它也不是最终整合GPU结果。
- 最终本轮白名单副本与原版分别完成窗口300模拟秒压力测试，各13项通过，无引擎错误。RTX 5060、NVIDIA 621.01、OpenGL 3.3兼容渲染、540×960、Dummy音频：末30秒物理均值35.88276→31.27243毫秒，P95为74.002→64.436毫秒；帧均值38.18563→33.660253毫秒，P95为76.336→66.802毫秒，平均帧耗时下降约12%。候选静态内存248539177→250022397字节，地格764→765、喷溅记录54→52；没有该夹具下无限增长的证据，但不代表自然长时、无限队伍或手机稳定。
- 候选每段存档均值22.629～34.085毫秒、快照2.2666～3.5645毫秒，仍有慢帧。没有把加速300模拟秒说成自然游玩五分钟，也不承诺稳定60帧或彻底消除卡顿。
- 首轮白名单回归中的节点旧交互和表面深度两组，在固定原版同样失败，分别依赖已取消的手动节点流程与不存在的`brush_fx.styles`；保留失败，不为通过而恢复旧接口。旧房尺寸/屋顶断言改为独立石碑面法线；旧染色夹具改用完整敌人记录，不放宽存档校验。复测染色116项、生命周期72项、旧染色适配72项通过。

## 复现入口与证据

依赖本机Godot 4.7.2 Windows console与Python 3.14.5。玩家入口仍是[开始完整版游戏.cmd](../../../开始完整版游戏.cmd)，正常启动先由[launch.ps1](../../../src/game/launch.ps1)导入资源。本次验证使用[隔离检查驱动](../../../tools/verify_formal_architecture.py)的独立APPDATA、LOCALAPPDATA、TEMP和TMP目录；不对真实PaintedStar存档运行压力脚本。GPU使用兼容渲染与Dummy音频，避免音频设备异常污染渲染结论。

在仓库根目录运行：

```powershell
python -B tools/lint.py --base 35b465a --report _local/long-session-20261117/lint-final.json
python -B _local/long-session-20261117/prepare_task.py
python -B _local/long-session-20261117/run_suite.py task-only
python -B _local/long-session-20261117/run_probe.py before gpu
python -B _local/long-session-20261117/run_probe.py task-only gpu
```

临时驱动[prepare_task.py](../../../_local/long-session-20261117/prepare_task.py)仅首次建立task-only副本，已有证据时拒绝覆盖；[run_suite.py](../../../_local/long-session-20261117/run_suite.py)串行执行导入、语法、启动与规则/GPU专项；[run_probe.py](../../../_local/long-session-20261117/run_probe.py)驱动[压力夹具](../../../_local/long-session-20261117/long_session_probe.gd)。它们是本轮复现资料，不是发行入口。其他会话变更的成长、队伍和UI文件不在白名单中；基线、副本哈希与排除清单随结果保存。

长期保留的回归入口为[石碑/地物真实场景](../../../src/game/full_game/stele_dye_scene_test.gd)、[旧档迁移](../../../src/game/full_game/stele_geometry_save_test.gd)、[喷溅网格oracle及缓存预算](../../../src/game/full_game/splash_mesh_budget_test.gd)与[原性能契约](../../../src/game/full_game/performance_test.gd)。后续不保留_local时，可用正式隔离检查驱动运行这些专项；压力数值仅适用于本次固定夹具与机器。

## 未验与残余风险

- 未做手机、Web包、自然长时生存、整球长途移动、无限大队伍或真人美术/手感验收。
- 地物染色当前跟随地面顶色，不支持独立叶片命中、流淌、黏度或半透明颜料体积。
- 旧建筑局部染色映射为几何重采样近似；严格存档验证和玩法字段不变，不等于旧涂层逐像素重现。
- 存档和快照仍有开销；本轮不把构网提速说成彻底消除所有卡顿。
